# 📚 Tutor Management System
## Description:
Project is a local app that lets its user keep track of the tutoring sessions they give, their students, info about them and current earnings. The app is made using PySide6. 

## What is done?
- most of the database functions,
- module of adding a new student,
- a prototype of adding new session

## What comes next?
- more attractive gui
- the view of all sessions
- the view of all students
- statistics
